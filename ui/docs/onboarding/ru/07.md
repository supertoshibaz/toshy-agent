# Файловая система

Слева снизу есть две вкладки виджетов — [«Папка проекта» и «Материалы»](toshy://onboarding/filesystem-tabs). В чём разница? Агент работает только с папкой проекта. Любые файлы, кроме `.md`, создаваемые тобой в пространстве «Файл», будут создаваться в папке проекта.

«Материалы» в свою очередь являются хранилищем файлов `.md` из текстового редактора, `.canvas` из доски и `.tpaint` из скетча. Это сделано, чтобы не засорять проект своими записями, и наоборот. При желании ты можешь назначить в виджете материалов ту же папку, что и рабочая.

При этом в рабочих пространствах ты видишь все открытые тобой вкладки разом, независимо от выбранного проекта и рабочей папки.
