# Первый запуск

Чтобы запустить ядро агента, открой пространство [«Запуск»](toshy://onboarding/startup-tab). В настройках создай профиль API твоей модели, сохрани, а затем нажми на круглую кнопку [«Startup»](toshy://onboarding/core-start). Она окружена дольками — это переключатели модулей. На внутреннем кольце расположены встроенные системные модули. На внешнем кольце будут располагаться твои кастомные модули.

На будущее - Ядро можно запускать и выключать в любой момент, но некоторые функции приложения доступны только при активном ядре.
