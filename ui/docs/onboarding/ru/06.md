# Функции чата

- [Плюсик](toshy://onboarding/chat-attach) просто открывает файловую систему, чтобы отправить модели любой файл.
- [Бирочка](toshy://onboarding/chat-tags) открывает панель тегов. Их можно включать/выключать, добавлять и удалять. Теги — это короткие команды для модели, которые прикрепляются к твоим сообщениям как часть запроса. Для модели это выглядит примерно так: «Только для этого сообщения: Тег».

- Под [гаечным ключом](toshy://onboarding/chat-tools) лежат:
  - «Чистый запрос» — отправка запроса без передачи контекста и системных промптов. Это нужно, например, при запуске модели, которая не ведёт диалог, а просто обрабатывает входные данные.
  - «Разрешить полное чтение веб-страниц» — пока пункт активен, результаты веб-поиска загружаются напрямую в контекст модели, а не в память, к которой она обычно обращается.
  - Пункты «Скиллы» и «Пайплайны» заставляют модель применить указанные тобой элементы, если они есть в кастомных модулях.

Из прочего:

- Дополнительные запросы можно отправлять прямо во время генерации: модель учтёт их в рамках той же генерации.
- Сообщения можно выделять сразу пачками, просто проведя слева от них курсором с зажатой левой кнопкой мыши.
- При редактировании своего запроса можно сразу перегенерировать ответ модели.
