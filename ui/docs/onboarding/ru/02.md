# Сущности интерфейса

Здесь есть всего три сущности, на которых построен почти весь интерфейс:

1. [Верхняя / Нижняя панели](toshy://onboarding/panels) — содержат вкладки рабочих пространств и прочее.
2. [Рабочие пространства](toshy://onboarding/workspace-tabs) — в таких местах ты непосредственно работаешь над своими проектами или агентом.
3. [Виджеты](toshy://onboarding/widget-tabs) — это вкладки на боковых панелях с функционалом, который может пригодиться независимо от рабочего пространства.
