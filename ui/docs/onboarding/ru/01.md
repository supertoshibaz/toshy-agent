# Добро пожаловать!

Привет! Это небольшой гайд о том, как начать пользоваться агентом и этим приложением.
Если хочешь начать мгновенно, настройки API перед тобой — [вбивай](toshy://onboarding/api-create) и переключайся в [чат](toshy://onboarding/chat-tab).

Снизу расположены стрелочки для пролистывания страниц онбординга. Крестик закроет виджет через 3 секунды после нажатия. Его можно будет вновь открыть [здесь](toshy://onboarding/info-menu).

Язык или тему можно сменить в [настройках персонализации](toshy://onboarding/personalization).
