# Задачи сессии

Ты мог заметить виджет [«Задачи»](toshy://onboarding/tasks-tab) справа сверху. Их также можно увидеть в настройках сессии в пространстве [«Проект»](toshy://onboarding/projects-tab).

Во время работы модель сама или по прямой просьбе создаёт задачи, которые сразу получают статус «В работе». Также ты сам можешь их создавать. Самостоятельно модель не может закрывать задачи: это делается только при ручном запросе кнопкой «Обновить статусы», чтобы модель в произвольный момент времени не могла за тебя решать, закончил ты работу над чем-то или нет.

Эта система необходима, чтобы ты мог быстро посмотреть, что делалось и что осталось незавершённым в какой-либо сессии.
