# Обращение к модели

Перейди в пространство [чата](toshy://onboarding/chat-tab). Попробуй что-то написать и отправить модели.

Обрати внимание: на виджете [«Сессии»](toshy://onboarding/sessions-tab) автоматически создался проект, под которым лежит начатая тобой сессия. Проект — это папка для сессий, от которой последние наследуют настройки. Ты можешь настраивать их в пространстве [«Проекты»](toshy://onboarding/projects-tab) на верхней панели.
