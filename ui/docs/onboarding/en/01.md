# Welcome!

Hi! This short guide will help you get started with Toshy and studio app.
If you want to start instantly, the API settings are right in front of you there — [fill them in](toshy://onboarding/api-create) and then switch to [Chat](toshy://onboarding/chat-tab).

Use the arrows below to turn onboarding pages. The cross closes the onboarding widget 3 seconds after you click it. You can reopen it [here](toshy://onboarding/info-menu).

You can change the language or theme in [Personalization settings](toshy://onboarding/personalization).
