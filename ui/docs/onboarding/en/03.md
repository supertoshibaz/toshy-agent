# First launch

To start the agent core, open the [Startup](toshy://onboarding/startup-tab) workspace. Create and save an API profile for your model in the settings, then click the round [Startup](toshy://onboarding/core-start) button. The segments around it are module switches. Built-in system modules appear in the inner ring, while your custom modules appear in the outer ring.

Note: You can turn on or off core at any time, but some functions require core to be enabled.
