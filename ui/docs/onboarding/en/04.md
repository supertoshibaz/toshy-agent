# Talking to the model

Go to the [Chat](toshy://onboarding/chat-tab) workspace. Try writing a message and sending it to the model.

Notice that a project was automatically created in the [Sessions](toshy://onboarding/sessions-tab) widget, containing the session you just started. A project is a folder for sessions, which inherit their settings from it. You can configure them in the [Projects](toshy://onboarding/projects-tab) workspace on the top panel.
