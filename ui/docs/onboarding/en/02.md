# Interface essentials

Almost the entire interface is organized around just three elements:

1. [Top / Bottom panels](toshy://onboarding/panels) — contain workspace tabs and other controls.
2. [Workspaces](toshy://onboarding/workspace-tabs) — these are where you work directly on your projects or on Toshy.
3. [Widgets](toshy://onboarding/widget-tabs) — tabs in the side panels containing tools you may need independently of the current workspace.
