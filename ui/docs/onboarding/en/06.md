# Chat features

- The [plus button](toshy://onboarding/chat-attach) opens the file manager so you can attach any file to chat.
- The [tag button](toshy://onboarding/chat-tags) opens the tags panel. Tags can be enabled, disabled, added, and removed. They are short instructions to the model, attached to your messages as part of the request. To a model, this looks something like: “For this message only: Tag.”

- Under the [wrench](toshy://onboarding/chat-tools), you'll find:
  - “Clean Request” — sends the request without conversation context or system prompts. This is useful, for example, when running a model that processes input rather than conducting a conversation.
  - “Allow Full Web Page Reading” — while enabled, web search results are loaded directly into the model's context instead of memory, which it would normally consult.
  - “Skills” and “Pipelines” — instruct the model to use the selections you specify, when they exist in custom modules.

A few other things:

- You can send additional requests during generation. The model will take them into account within the same generation.
- You can select several messages at once by dragging along their left side with the left mouse button held down.
- When editing your own prompt, you can immediately regenerate the model's answer.
