# Session tasks

You may have noticed the [Tasks](toshy://onboarding/tasks-tab) widget in the top-right panel. You can also view tasks in the session settings in the [Projects](toshy://onboarding/projects-tab) workspace.

While working, the model can create tasks on its own or at your request. New tasks immediately receive the “In Progress” status. You can create tasks yourself too. The model cannot close tasks on its own: that only happens when you explicitly request a status update with the “Update Statuses” button. This prevents the model from deciding for you whether you've finished something.

This system helps you quickly see what has been done and what remains unfinished in a session.
