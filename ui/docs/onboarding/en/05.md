# About Chat

Chat has a lot of features. Hover over a message and several buttons will appear. Hover over each button, and a tooltip will explain its function after a moment. Let's go through other chat features, its important.

These tooltips appear throughout the application. If they become distracting, you can [disable them in settings](toshy://onboarding/tooltip-settings). There are also many features in the message input bar. We'll cover those next.
