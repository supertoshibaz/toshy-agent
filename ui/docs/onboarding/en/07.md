# File system

There are two widget tabs at the bottom left: [Project Folder and Materials](toshy://onboarding/filesystem-tabs). What's the difference? The agent works only with the project folder. Any non-`.md` files you create in the File workspace are created in that project folder.

Materials stores `.md` files from the text editor, `.canvas` files from the Board, and `.tpaint` files from Sketch. This keeps your notes separate from project files, and vice versa. If you prefer, you can set the Materials folder to the same folder as the project workspace.

Across workspaces, you can see all the tabs you've opened regardless of the selected project or working folder.
