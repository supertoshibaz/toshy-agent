# Toshy Agent
by supertoshibaz

Toshy is a modular, graph-based AI agent written in Python. The agent comes with Toshy Studio, a desktop application that makes it easy to build complex AI pipelines, work on a project from start to finish in one application, and use any local or cloud models.
Currently, Studio's functionality is focused on coding, working with text, research, planning, and everyday tasks.

## What makes it different from the others?
### Modularity
Toshy's architecture is modular. Modules are easy to create, enable, and disable on the fly without restarting the agent. And if something goes wrong, a failing module usually won't bring down the entire agent.

### Graph Engineering
You can easily build a controlled topology of any complexity for the model's workflow in a convenient graphical interface. It's simple; there's no complicated puzzle to figure out.

### Parallel work
Toshy Studio is designed for working in multiple chats simultaneously, allowing you to track generation status and tasks being performed or already completed in each session.

### User-Friendly philosophy
Toshy Studio aims to offer a large amount of functionality while remaining simple and transparent. Nothing is hidden in random places five tabs deep.

### All in one application
Out of the box, Toshy Studio lets you draw sketches, build diagrams on a board, and work in a text editor, so you don't have to constantly switch between three or four applications.

### Plugin system
You can develop and install plugins for Studio that extend the functionality of both the agent itself and the Studio application.

### Advanced chat features
Branches, replies, quotes, pinned messages, forwarding, search, sending requests during generation, tags, and much more.
